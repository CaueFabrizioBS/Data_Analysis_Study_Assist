## Percorrendo um dicionário

```python
financial_info = {'American Express': 93.23, 'Boeing': 178.44, 'Nike': 97.99}

for key in financial_info.keys():          # só as chaves (é o padrão do "for key in dic")
    print(key)
for value in financial_info.values():      # só os valores
    print(value)
for key, value in financial_info.items():  # os dois juntos
    print(key, value)

total_value = 0
for value in financial_info.values():
    total_value += value
```

## Estruturas aninhadas

**Dicionário de listas:** cada chave guarda uma lista.

```python
bus_schedule = {
    '72': ['8:00', '12:00', '17:30'],
    '26': ['9:30', '15:00'],
}
for route, times in bus_schedule.items():   # os nomes route e times são livres
    for time in times:
        print(f'Linha {route} - Partida {time}')

```

## Funções: parâmetros e retornos

Parâmetro com valor padrão é **opcional**; sem padrão é **obrigatório**. Os obrigatórios vêm antes na definição.

```python
def filter_by_genre(data, genre='drama'):
    filtered_result = []
    for row in data:
        if genre in row[3]:              # 'drama' in 'drama, crime' → True
            filtered_result.append(row)
    return filtered_result
```

**Vários `return`:** a função para no primeiro `return` que alcançar.

```python
def omelet(eggs_number=2):
    if eggs_number > 0:
        return 'A omelete está pronta! Ovos usados: ' + str(eggs_number)
    else:
        return 'Como fazer uma omelete sem ovos?'
    print('Eu nunca serei impressa :(')     # código depois de return não roda
```

**Devolver vários valores:** separe por vírgula. O Python devolve uma **tupla**, que você desempacota na mesma ordem:

```python
def find_area_and_perim(side1, side2):
    area = side1 * side2
    perimeter = 2 * (side1 + side2)
    return area, perimeter

find_area_and_perim(2, 3)                       # (6, 10)
rec_area, rec_perimeter = find_area_and_perim(7, 3)    # 21 e 20
```

## Series a fundo

Uma Series é uma coluna solta: valores mais um índice. Atributos úteis: `.name` (nome da coluna) e `.size` (quantidade de elementos).

| Quero | `.loc` | Abreviado |
|---|---|---|
| Um elemento | `s.loc[7]` | `s[7]` |
| Vários | `s.loc[[5, 7, 10]]` | `s[[5, 7, 10]]` |
| Fatia | `s.loc[5:10]` (inclui o 10) | `s[5:10]` (não inclui o 10) |

**Filtro numa Series:** a condição gera uma Series de `True`/`False`; colocada entre colchetes, filtra.

```python
total_play = df['total play']
lower_20 = total_play < 20        # máscara booleana
total_play[lower_20]              # só os valores < 20 (Series)
df[lower_20]                      # a mesma máscara filtra o DataFrame inteiro
```

## Estatística descritiva com pandas

```python
df['total_play'].max()                               # o valor
df[df['total_play'] == df['total_play'].max()]       # a linha inteira desse valor

df_drop_skip = df[df['total_play'] > 30]             # tira as músicas puladas
df['total_play'].median(), df_drop_skip['total_play'].median()   # 21.3 → 202.0
df['total_play'].mean(), df_drop_skip['total_play'].mean()       # 99.7 → 206.1
```

> [!dica] Limpar aproxima média e mediana
> Com as músicas puladas (poucos segundos), a mediana era 21 e a média 100: distribuição bem assimétrica. Tirando os pulos, as duas ficam perto de 200. Filtrar o que não interessa muda a conclusão.
