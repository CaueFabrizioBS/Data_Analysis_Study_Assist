## Scripts com argumentos (argparse)

Um script `.py` que sempre abre `'tripleten_logo.jpeg'` só serve para essa imagem. Com `argparse`, quem roda o script no terminal escolhe:

```python
# image_rotator.py
import argparse
from PIL import Image

parser = argparse.ArgumentParser()
parser.add_argument('input_file', help='input file path')          # posicional
parser.add_argument('output_file', help='output file path')        # posicional
parser.add_argument('--angle', '-a', type=int, default=90,
                    help='rotação anti-horária (graus)')            # opcional
parser.add_argument('-i', '--info', action='store_true',
                    help='exibir tamanho da imagem')                # sinalizador
args = parser.parse_args()

im = Image.open(args.input_file)
if args.info:
    print('dimensões:', im.size)
im.rotate(args.angle).save(args.output_file)
```

```bash
python image_rotator.py logo.jpeg out.png --angle 180 -i
python image_rotator.py -h        # ajuda gerada a partir dos help=
```

| Tipo | Como se escreve | Regra |
|---|---|---|
| Posicional | `'input_file'` | Obrigatório, na ordem definida |
| Opcional | `'--angle', '-a'` | Pode vir em qualquer lugar, com o nome antes. Tem `default` |
| Sinalizador | `action='store_true'` | Sem valor. Presente = `True`, ausente = `False` |

## Escopo e argumentos de função

Escopo: **local** (dentro da função, tem prioridade), **global** (fora de funções), **integrado** (*built-in*: `print`, `len`, `slice`...).

| Argumento | Exemplo |
|---|---|
| Posicional | `trip_price(409, 35)` na ordem da definição |
| Nomeado | `trip_price(price=3.8, mpg=35, dist_miles=409)`, qualquer ordem |
| Misto | `trip_price(409, 35, price=3.8)`: posicionais **antes** dos nomeados |
| Padrão | `def f(loc_from='A')`: usado se ninguém passar outro |

## Dicas de tipo e mypy

```python
def list_of_words(text: str, sep: str = " ") -> list:
    return text.split(sep)
```

O Python **não** confere os tipos ao rodar: `list_of_words("a b", sep=None)` funciona. O `mypy` analisa o arquivo e avisa:

```bash
mypy list_of_words.py
# error: Argument "sep" has incompatible type "None"; expected "str"
```

## Exceções: try / except / else / finally

```python
try:
    im = Image.open(args.input_file)          # tenta
except FileNotFoundError:
    print('arquivo não encontrado')           # erro específico primeiro
except Exception as error_msg:
    print(error_msg)                          # qualquer outro erro
else:
    print('funcionando sem problemas')        # só se NÃO deu erro
finally:
    im.close()                                # SEMPRE roda
```

> [!dica] finally é fechar a geladeira
> Você abre a geladeira procurando algo para beber. Achando ou não, fecha a porta. Em dados: fechar a conexão com o banco ou o arquivo, com erro ou sem erro.

## Módulos, pacotes e bibliotecas

**Módulo** é um arquivo `.py`. **Pacote** é uma pasta de módulos. **Biblioteca** é um conjunto de pacotes.

```python
# module.py
import re
def check_email(string: str):
    if re.match(r'[.\w]+@\w+[.]\w+', string):    # expressão regular: algo@algo.algo
        print('correto')

# myscript.py (mesma pasta)
from module import check_email      # melhor que "import *": deixa claro o que veio de onde
```

**`if __name__ == '__main__':`** roda o bloco só quando o arquivo é executado direto (`python module_1.py`). Quando outro arquivo faz `import module_1`, o bloco é ignorado. Bom para testes rápidos.

## Programação orientada a objetos (classes)

Dicionários guardam dados, mas cada "personagem" vira uma cópia solta e as funções ficam separadas. Uma **classe** é um molde que junta **atributos** (dados) e **métodos** (funções).

```python
class Knight:
    def __init__(self, name):         # roda ao criar o objeto
        self.name = name              # self = o próprio objeto
        self.health = 100
        self.knowledge = 20

    def heal(self, amount=20):        # método normal: usa self
        self.health += amount

arthur = Knight('Arthur')             # objeto (instância)
arthur.heal(10)                       # health = 110
arthur.health = 150                   # atributo pode ser alterado direto
```

| Tipo de método | Decorador | Primeiro parâmetro | Uso típico |
|---|---|---|---|
| Normal (de instância) | nenhum | `self` | Ler ou mudar dados do objeto |
| Estático | `@staticmethod` | nenhum | Função utilitária que mora na classe mas não usa nem o objeto nem a classe |
| De classe | `@classmethod` | `cls` | Jeito alternativo de **criar** objetos |

```python
class Stock:
    def __init__(self, ticker, amount, price):
        self.ticker, self.amount, self.price = ticker, amount, price

    @staticmethod
    def show_current_price(ticker):     # Stock.show_current_price('AAPL')
        ...

    @classmethod
    def from_string(cls, string):       # cria um Stock a partir de 'ABC 10 1.5'
        ticker, amount, price = string.split()   # split() sem argumento já separa por espaço
        return cls(ticker, int(amount), float(price))

abc = Stock.from_string('ABC 10 1.5')
```

**Herança:** a classe filha recebe tudo da classe pai e acrescenta o que é dela.

```python
class Character:
    def __init__(self, name):
        self.name = name
        self.health = 100

class Knight(Character):
    def __init__(self, name):
        super().__init__(name)     # roda o __init__ do pai
        self.damage = 25
```

## Arquivos (file I/O)

```python
with open('my_file.txt') as f:           # 'r' (leitura) é o padrão
    for line in f:
        print(line.rstrip())             # tira o \n do fim
```

O `with` fecha o arquivo sozinho ao sair do bloco. Sem ele, chame `f.close()`.

| Leitura | Devolve |
|---|---|
| `f.read()` | O arquivo inteiro numa string |
| `f.readlines()` | Lista com uma string por linha (cada uma com `\n`) |
| `for line in f` | Uma linha por vez (bom para arquivos grandes) |

| Modo | Faz |
|---|---|
| `'r'` | Lê (padrão) |
| `'w'` | Cria ou **sobrescreve** |
| `'a'` | Acrescenta no fim (cria se não existir) |

```python
with open('output.txt', 'w') as f:
    f.writelines(['linha 1\n', 'linha 2\n'])
```

**ZIP:**

```python
from zipfile import ZipFile
with ZipFile('archive.zip', mode='a') as archive:
    archive.write('logs.txt')
    archive.printdir()                       # lista o conteúdo
with ZipFile('archive.zip') as archive:
    with archive.open('logs.txt') as f:
        print(f.read().decode())             # dentro do zip vem em bytes
```

## JSON e YAML

Formatos de texto para guardar e trocar dados estruturados. JSON é o padrão das APIs; YAML é mais fácil de ler (usado em arquivos de configuração).

| Função | Faz |
|---|---|
| `json.loads(texto)` | Texto JSON → objeto Python |
| `json.load(f)` | Arquivo JSON → objeto Python |
| `json.dumps(obj)` | Objeto Python → texto JSON |
| `json.dump(obj, f)` | Objeto Python → grava no arquivo |
| `yaml.dump(obj)` | Objeto Python → texto YAML |

Macete: o **s** no fim é de **s**tring.

## APIs web

API é a "porta" que um sistema abre para outros programas pedirem dados. Você manda uma requisição para um **endpoint** (URL) e recebe a resposta, quase sempre em JSON.

```python
import requests

params = {'from': 'USD', 'to': 'GBP', 'amount': 20}
res = requests.get('https://api.frankfurter.app/latest', params=params)
res.json()                         # {'amount': 20.0, 'base': 'USD', 'rates': {'GBP': 15.36}}
res.headers['Content-Type']        # cabeçalhos da resposta

url = 'https://collectionapi.metmuseum.org/public/collection/v1/objects/437133'
requests.get(url).json()['artistDisplayName']      # 'Claude Monet'
```

Os parâmetros podem ir no dicionário `params` ou direto na URL (`?from=USD&to=GBP`). Algumas APIs exigem uma **chave de API** (um token, tipo senha), que vai numa variável de ambiente.

## Qualidade de código

- **pylint**: analisa estilo e dá nota de 0 a 10. Aponta ponto e vírgula sobrando, falta de linha final, falta de *docstring*.
- **docstring**: o texto entre `"""` logo abaixo do `def`, explicando o que a função faz.
- **pytest**: roda automaticamente as funções que começam com `test_`. Dentro delas, `assert` confere o resultado:

```python
def test_get_age_group():
    assert get_age_group(-1) == 'desconhecido'
    assert get_age_group(8) == 'crianças'
```
