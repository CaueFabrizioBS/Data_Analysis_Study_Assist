## O que é e como abrir

A CLI (*command-line interface*) é o terminal: você digita comandos em vez de clicar. Serve para mexer em arquivos, rodar scripts e automatizar tarefas.

| Sistema | Como abrir |
|---|---|
| Windows | `Win + R` → `cmd`, ou procurar "PowerShell" |
| macOS | `Cmd + Espaço` → "Terminal" |
| Linux | `Ctrl + Alt + T` |
| Jupyter | New → Terminal |

O terminal abre no diretório **home** (`~`), a pasta do seu usuário. Os comandos abaixo são do Linux/macOS (bash), os mesmos do terminal do Jupyter.

## Anatomia de um comando

```text
ls -r -a sql_project
↑  ↑      ↑
comando  opções (flags)  argumento
```

- `comando --help`: resumo das opções.
- `man comando`: o manual completo.

## Navegar

| Comando | Significa | Faz |
|---|---|---|
| `pwd` | *print working directory* | Mostra onde você está |
| `ls` | *list* | Lista arquivos e pastas em ordem alfabética |
| `ls -a` | *all* | Inclui os ocultos (nomes que começam com `.`) |
| `ls -r` | *reverse* | Ordem inversa |
| `cd pasta` | *change directory* | Entra na pasta |
| `cd ..` | | Sobe um nível |
| `cd ~` | | Vai para o home |

> [!corrigido]
> No caderno ficou: "pwd = print working disk", "cd = change disk".
> O certo: *print working **directory*** e *change **directory***.

> [!def] Caminho relativo × absoluto
> - Relativo, a partir de onde você está: `cd ./intro_to_ml/`. O `.` é a pasta atual, o `..` é a pasta de cima.
> - Absoluto, desde a raiz: `cd /home/anthony/edu_materials/intro_to_ml/`.

**Atalhos:** `clear` limpa a tela; seta para cima repete comandos anteriores; `Tab` completa nomes (aperte duas vezes para ver as opções).

## Criar, copiar, mover, apagar

| Comando | Faz |
|---|---|
| `mkdir a b c` | Cria pastas (várias de uma vez, separadas por espaço) |
| `mkdir -p pai/filho` | Cria a pasta pai junto, se ainda não existir |
| `touch arquivo.txt` | Cria um arquivo vazio |
| `cp origem destino` | Copia arquivo |
| `cp -r pasta destino` | Copia pasta com conteúdo |
| `mv origem destino` | Move ou renomeia |
| `rm arquivo` | Apaga arquivo |
| `rm -d pasta` | Apaga pasta **vazia** |
| `rm -r pasta` | Apaga pasta com tudo dentro |

Opções úteis: `-v` (*verbose*) mostra o que foi feito; `-i` pergunta antes (responda `y` ou `n`).

> [!erro] rm não tem lixeira
> O que o `rm` apaga não volta. Use `-i` quando tiver dúvida, principalmente com `-r` e coringas.

## Ver e escrever conteúdo

| Comando | Faz |
|---|---|
| `cat arquivo` | Mostra o conteúdo |
| `echo "texto" > arq` | Escreve no arquivo, **substituindo** o que havia |
| `echo "texto" >> arq` | **Acrescenta** no fim |
| `cat > arq` | Digita conteúdo direto (Ctrl + D termina) |
| `wc arquivo` | Linhas, palavras e bytes: `1 5 17 teste.txt` |
| `head -n 2 arq` / `tail -n 2 arq` | Primeiras / últimas linhas |

## Coringas (wildcards)

| Coringa | Casa com | Exemplo |
|---|---|---|
| `*` | Qualquer sequência de caracteres | `*.jpg`, `foto_*.jpg` |
| `?` | Exatamente um caractere | `foto_?.jpg` pega `foto_1`, não `foto_10` |
| `[ ]` | Um caractere da lista ou faixa | `A[cgp]e.txt`, `A[a-j]e.txt` |
| `{ }` | Qualquer um dos padrões | `ls {file*.txt,A[a-j]e.txt}` |

## Buscar

**find** procura arquivos por nome, tipo ou data:

```bash
find . -name "relatorio.csv"      # nome exato, na pasta atual (.)
find ~ -iname "*.CSV"             # ignora maiúscula/minúscula, no home (~)
find . -type f                    # só arquivos (d = pastas)
find . -mtime -2                  # modificados há menos de 2 dias
find . -mmin -30                  # modificados há menos de 30 minutos
find . -name "*.txt" -delete      # apaga o que achou (cuidado!)
```

**grep** procura texto **dentro** dos arquivos:

```bash
grep "buy" bike.txt        # linhas com "buy" (pega "buying" também)
grep -w "buy" *            # palavra inteira, em todos os arquivos da pasta
grep -i "buy" *            # ignora maiúscula/minúscula
grep -c "buy" *            # conta as linhas que batem, por arquivo
grep -l "buy" *            # só o nome dos arquivos que têm
```

## Pipes `|`

O `|` manda a **saída** de um comando como **entrada** do próximo:

```bash
cat super_text_file.txt | grep "python" | head -3
history | grep "cat"
```

## Histórico

`history` lista os comandos já usados; `history 3` mostra os 3 últimos; `history > historico.txt` salva num arquivo.

## Alias

Apelido para um comando longo:

```bash
alias cdp="cd /home/student/work/my_amazing_project"
unalias cdp
```

Para durar entre sessões, coloque a linha no arquivo `~/.bashrc`.

## Variáveis de ambiente

```bash
MY_V="valor"                       # variável do shell: só esta janela, só o shell
export MY_V="my first variable"    # variável de ambiente: programas abertos daqui enxergam
echo $MY_V                         # mostra o valor
printenv                           # lista todas
```

Para ficar permanente no Linux: adicione `MY_V="..."` ao arquivo `/etc/environment`.

No Python:

```python
import os
os.environ.get("MY_V")     # None se não existir
```

> [!dica] Por que isso importa
> Senhas e chaves de API vão em variáveis de ambiente, nunca escritas no código que vai para o GitHub.
