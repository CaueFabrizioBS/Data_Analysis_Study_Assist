## O básico

Lista é uma coleção ordenada entre colchetes. Pode misturar tipos e até ter listas dentro.

```python
favorite_films = ['The Graduate', 'Reservoir Dogs', 'Fear and Loathing in Las Vegas']
len(favorite_films)    # 3  (conta itens, não caracteres)

my_list = ['<3', 77, 3.89, True, False, ['sub', 'list', 0.2]]
len(my_list)           # 6  (a sublista conta como 1 item)
```

## Índices e fatias

Funcionam igual às strings, só que cada posição é um item.

```python
movie_info = ['Fight Club', 1999, ['thriller', 'drama', 'crime'], 139, 8.644]
movie_info[1:4]    # [1999, ['thriller', 'drama', 'crime'], 139]  (fatia de lista é lista)
```

## Modificando listas

| Método | Faz o quê |
|---|---|
| `.append(x)` | Coloca **um** item no fim |
| `.extend([x, y])` | Coloca **vários** itens no fim |
| `.insert(i, x)` | Coloca um item na posição `i` |
| `.pop()` | Remove e devolve o último item |
| `.pop(i)` | Remove e devolve o item da posição `i` |

```python
movies = ['Matrix', 'Matrix 2', 'Matrix 3']
popped_value = movies.pop(1)
print(popped_value)   # Matrix 2
print(movies)         # ['Matrix', 'Matrix 3']
```

> [!erro] append com lista cria sublista
> `lista.append(['a', 'b'])` adiciona **uma** sublista. Para adicionar `'a'` e `'b'` como itens soltos, use `extend`.

## Ordenando

| | `lista.sort()` | `sorted(lista)` |
|---|---|---|
| O que é | Método | Função |
| Altera a original? | Sim | Não, devolve uma lista nova |
| Retorno | `None` | A lista ordenada |

Os dois aceitam `reverse=True` para ordem decrescente.

> [!erro] Armadilha clássica
> `nova = years.sort()` deixa `nova` valendo `None`. Use `nova = sorted(years)`.

Strings são ordenadas pela tabela de caracteres: espaço e a maior parte da pontuação, depois números, depois maiúsculas (A→Z), depois minúsculas (a→z). Por isso `'banana'` vem depois de `'Zebra'`.

## Listas aninhadas (tabelas)

Uma lista de listas funciona como tabela: cada sublista é uma linha.

```python
movies_info[0]       # primeira linha inteira
movies_info[0][2]    # linha 0, coluna 2  → 1994
movies_info[-1][0]   # última linha, coluna 0 → 'Good Will Hunting'
```

> [!regra] Primeiro a linha, depois a coluna
> `tabela[linha][coluna]`

## Atribuição composta

Atalhos para atualizar uma variável usando o próprio valor dela:

| Atalho | Equivale a |
|---|---|
| `x += 5` | `x = x + 5` |
| `x -= 5` | `x = x - 5` |
| `x *= 5` | `x = x * 5` |
| `x /= 5` | `x = x / 5` |

## sum, max, min

```python
movies_duration = [142, 175, 152, 195, 201, 154, 178, 139, 133, 126]
sum(movies_duration)   # 1595
max(movies_duration)   # 201
min(movies_duration)   # 126
```
