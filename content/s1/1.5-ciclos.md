## for

Repete um bloco de código para cada item de uma lista (ou caractere de uma string). Em vez de cinco `print(film_genres[0])`, `print(film_genres[1])`..., você escreve:

```python
film_genres = ['scifi', 'drama', 'thriller', 'comedy', 'action']
for value in film_genres:
    print(value)
```

```desenho for-esteira
o for pega um item de cada vez, como uma esteira
```

```text
for  element  in  your_list:
     ↑ variável do ciclo  ↑ o que vamos percorrer
    print(element)   ← indentação de 4 espaços: o que roda a cada volta
```

- O nome da variável do ciclo é livre.
- Não esqueça os dois pontos `:` no fim da linha do `for`.
- Tudo que está indentado embaixo roda a cada item.
- Numa string, o `for` passa por cada caractere, um por vez.

```python
for n in [42, 51, 12]:
    print(n + 5)             # 47, 56, 17

for item in ['calça', 'rua']:
    print(item + ' azul')    # calça azul, rua azul
```

## for em tabela (lista aninhada)

Cada volta do ciclo recebe uma linha inteira. Escolha a coluna pelo índice:

```python
for row in movies_info:
    print(row[0])      # imprime só os títulos
```

> [!corrigido]
> No caderno ficou: "`variável[][]`: primeiro coluna, depois linha".
> O certo: primeiro a **linha**, depois a **coluna**.

## while

Repete **enquanto** uma condição for verdadeira. Usado quando você não sabe quantas voltas vão ser.

```desenho while-elevador
o elevador aceita gente enquanto não lota
```

```python
from random import randint      # função que sorteia inteiros

capacity = 400
total_weight = 0
num_people = 0

while total_weight < capacity:
    person_weight = randint(30, 120)
    total_weight += person_weight
    num_people += 1
    print(f'Uma pessoa entra. Carga do elevador: {total_weight}')

print(f'Elevador lotado. {num_people} pessoas já estão no elevador')
```

A condição é checada **antes** de cada volta. Quando `total_weight` passa de 400, o ciclo para e o código segue para a linha de baixo.

## for × while

| | `for` | `while` |
|---|---|---|
| Para quando | Acabam os itens | A condição vira `False` |
| Use quando | Tem uma coleção para percorrer | Depende de algo que muda dentro do ciclo |
| Risco | Baixo | Ciclo infinito |

> [!erro] Ciclo infinito
> Acontece quando a condição do `while` nunca vira `False`.
> ```python
> sales = 1000
> while sales > 100:
>     sales += 1      # sales só cresce, nunca fica ≤ 100
> ```
> Sempre confira: alguma coisa dentro do ciclo leva a condição a ficar falsa?
