## O que faz um analista de dados

O analista pega dados brutos e transforma em algo que outra pessoa entende e usa para decidir. Num projeto, o caminho costuma ser este:

1. **Coletar e entender os requisitos do cliente.** Quem é o cliente e o que ele espera receber.
2. **Coletar dados relevantes.** Achar as fontes e padronizar tudo para dar para analisar junto.
3. **Analisar.** Aplicar os métodos que respondem à pergunta do cliente.

```fluxo
Coleta de requisitos → Combinação de dados → Preparação dos dados → Análise
```

## Jupyter Notebook

É um documento interativo onde código, texto e gráficos ficam juntos. É a ferramenta padrão para explorar um conjunto de dados e apresentar os insights.

| Célula de código | Célula de markdown |
|---|---|
| Executa Python (`2 + 2` mostra `4`) | Formata texto (`# Meu primeiro projeto` vira título) |

> [!def] Os dois modos de uma célula
> - **Modo comando** (barra azul ao lado): você mexe na célula como um todo. Copia, apaga, move, executa.
> - **Modo edição** (barra verde): você está escrevendo dentro da célula.
>
> Cada célula executada ganha um número na ordem em que rodou: `In [1]`, `In [2]`... Se o número pular ou estiver fora de ordem, você rodou células em outra sequência, e isso pode mudar o resultado.
