## Variáveis

Uma variável é um nome que guarda um valor. Em vez de digitar `3.14159265358979` toda hora, você guarda em `pi` e usa o nome. Menos chance de erro de digitação e código mais limpo.

```python
pi = 3.14159265358979
print(pi + 1)        # 4.14159265358979
```

O valor pode mudar (por isso "variável"), e uma variável pode receber o valor de outra:

```python
person = 'Maxwell'
person = 'Max'       # sobrescreve
print(person)        # Max

first_variable = 'Max'
second_variable = first_variable
print(second_variable)   # Max
```

> [!regra] Regras para nomes
> - Começa com letra ou `_` (nunca com número).
> - Só letras, números e `_`. Sem espaço, sem hífen.
> - Python diferencia maiúscula de minúscula: `pd`, `Pd` e `_pd` são três variáveis diferentes.

## print() é uma função

O que vai dentro dos parênteses é o **argumento**. Texto vai entre aspas (simples ou duplas), número não. Para imprimir várias coisas de uma vez, separe por vírgula: o `print` coloca um espaço entre elas.

```python
emperor = 'Romulus Augustulus'
reign_start = 475
print(emperor, reign_start)    # Romulus Augustulus 475
```

## Tipos de dados

| Tipo | Nome no Python | Exemplos |
|---|---|---|
| Inteiro | `int` | `11`, `1107` |
| Ponto flutuante (decimal) | `float` | `3.14`, `0.539` |
| Texto | `str` | `'python'`, `"best"` |
| Booleano | `bool` | `True`, `False` |

O mesmo operador `+` faz coisas diferentes conforme o tipo:

```python
print('Chinese' + 'English')   # ChineseEnglish  (concatena)
print(0.017 + 0.539)           # 0.556
print(1107 + 1121)             # 2228
print(True + False)            # 1   (True vale 1, False vale 0)
```

> [!erro] Misturar texto com número dá erro
> `'Chinês é falado por ' + 1107` gera `TypeError: can only concatenate str (not "int") to str`.
> Saídas: `print('Chinês é falado por', 1107)` com vírgula, ou converter: `'... ' + str(1107)`.

## Conversão de tipos

- `int(x)` transforma em inteiro (corta as casas decimais, não arredonda).
- `float(x)` transforma em decimal.
- `str(x)` transforma em texto. Útil para CEP, telefone, códigos que não são para fazer conta.
- `type(x)` mostra o tipo atual.

```python
en_sites = int(10000000 * 0.539)   # 5390000  <class 'int'>

ch_total_speakers = '1107'            # é texto
ch_total_speakers = int(ch_total_speakers) + 10   # 1117. Como texto, essa soma daria erro

zipcode = str(90210)                  # <class 'str'>
float('Olá, mundo!')                  # ValueError: só converte texto que parece número
```

> [!corrigido]
> No caderno ficou: "converter inteiro em float com `int()` e o contrário com `float()`".
> O certo: `int()` converte **para** inteiro e `float()` **para** decimal.

## Operações aritméticas

| Operação | Símbolo | Exemplo |
|---|---|---|
| Soma / subtração | `+` `-` | `5 - 2 = 3` |
| Multiplicação | `*` | `5 * 2 = 10` |
| Divisão | `/` | `5 / 2 = 2.5` |
| Divisão inteira | `//` | `5 // 2 = 2`, `11.8 // 3 = 3.0` |
| Módulo (resto da divisão) | `%` | `14 % 3 = 2` |
| Potência | `**` | `3 ** 2 = 9` |

> [!regra] Ordem das operações: PEMDAS
> **P**arênteses → **E**xpoentes (`**`) → **M**ultiplicação e **D**ivisão (incluindo `//` e `%`) → **A**dição e **S**ubtração.
> Operações do mesmo nível vão da esquerda para a direita.

> [!corrigido] Opa, corrigindo!
> No caderno ficou: "PEMDAS: potência = `%`".
> O certo: o E é de **Expoentes** (`**`). O `%` é módulo e fica no nível da multiplicação e da divisão.

> [!dica] Lendo o módulo
> `14 % 3`: o maior múltiplo de 3 que cabe em 14 é 12 (3 × 4). Sobra 14 − 12 = **2**.
> `7 % 4`: cabe 4 uma vez, sobra **3**. `10 % 2` sobra **0** (divisão exata, é assim que se testa se um número é par).

## Porcentagem e "parcela"

Porcentagem é `parte / todo * 100`. Leia o enunciado com calma:

- "Qual a **parcela** de falantes nativos no total?" → divisão: `64.8 / 67.8 = 0.956` (95,6% são nativos).
- "Do total, quantos **não** são nativos?" → subtração: `67.8 - 64.8 = 3.0` milhões.

## Mensagens de erro

| Erro | Causa típica |
|---|---|
| `SyntaxError` | Sintaxe errada, como parêntese ou aspa sem fechar: `print('Oi'` |
| `ZeroDivisionError` | Divisão por zero: `777 / 0` |
| `TypeError` | Operação com tipo errado: `'um dois' + 5` |
| `NameError` | Usou uma variável que ainda não foi criada |
| `ValueError` | Tipo certo, valor impossível: `float('Olá')` |

## try / except

Faz o código seguir em frente quando algo dá erro, em vez de parar tudo.

```python
try:
    print(777 / 0)                  # tenta isso
except:
    print('Não é possível dividir por zero!')   # se der erro, faz isso
print('Seguimos adiante!')
```
