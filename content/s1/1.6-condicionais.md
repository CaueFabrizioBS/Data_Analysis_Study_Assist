## Expressões lógicas

Uma expressão lógica dá `True` ou `False`. É ela que decide qual caminho o código segue: SE isso for verdade, ENTÃO faça aquilo.

**Operadores de comparação:** `==` igual, `!=` diferente, `>`, `<`, `>=`, `<=`.

**Operadores lógicos:**

| Operador | Verdadeiro quando | Exemplo |
|---|---|---|
| `and` | As duas condições são verdadeiras | `5 > 2 and 3 < 5` → `True` |
| `or` | Pelo menos uma é verdadeira | `5 > 2 or 3 > 5` → `True` |
| `not` | Inverte o resultado | `not (5 > 2)` → `False` |

> [!erro] `=` não é `==`
> `=` guarda um valor numa variável. `==` pergunta se dois valores são iguais.

## Funções predicado (strings)

Devolvem `True` ou `False`:

- `.islower()`: todas as letras são minúsculas.
- `.isdigit()`: só tem dígitos.
- `.isalpha()`: só tem letras. Espaço ou pontuação já dão `False`.

## if / elif / else

```python
weather = 'chuva'

if weather == 'chuva':
    item = 'guarda-chuva'
elif weather == 'sol':
    item = 'chapéu'
elif weather == 'neve':
    item = 'gorro e cachecol'
else:
    item = 'nada'
```

- `if` testa a primeira condição.
- `elif` ("senão, se") só é testado se tudo acima deu `False`. Pode ter quantos quiser.
- `else` pega todo o resto. Não leva condição.
- Assim que um bloco é verdadeiro, os de baixo são ignorados.

## in: procurar um pedaço

```python
quote = 'O progresso é impossível sem mudança...'
if 'ogres' in quote:
    print('Onde há progresso, há ogres!')
```

`in` também funciona com listas: `'drama' in genres`.

## if dentro de for

Classificar cada item de uma lista:

```python
for year in years:
    if 1990 <= year <= 1999:
        print('anos 90')
    elif 2000 <= year <= 2009:
        print('anos 2000')
    else:
        print('Ano não definido')
```

**Corrigir um valor numa tabela:**

```python
for movie in movies:
    if movie[0] == "Schindler's List":   # achou a linha
        movie[1] = 1993                  # corrige outra coluna da mesma linha
```

**Filtrar uma tabela:** crie uma lista vazia antes do ciclo para guardar o resultado.

```python
movies_filtered = []
for movie in movies_info:
    if movie[2] > 1990 and movie[1] == 'USA':
        movies_filtered.append(movie)
```
