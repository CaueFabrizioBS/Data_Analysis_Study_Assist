## O que é

Criar colunas novas a partir das que já existem, para responder perguntas que os dados brutos não respondem direto.

## Colunas com contas

```python
df['total_sales'] = df['na_sales'] + df['eu_sales'] + df['jp_sales']
df['eu_sales_share'] = df['eu_sales'] / df['total_sales']     # parcela da Europa
```

A conta é feita linha a linha, e o resultado já entra no DataFrame como coluna.

## Colunas booleanas

```python
df['is_nintendo'] = df['publisher'] == 'Nintendo'
df['platform_check'] = df['platform'].str.lower().isin(['gb', 'wii'])
```

## Tipo category: economizar memória

Uma coluna com 16 mil linhas e só 31 valores distintos (plataformas) pode virar `category`. O pandas guarda os 31 nomes uma vez e, nas linhas, só um código.

```python
df['platform'] = df['platform'].astype('category')
```

| | `object` (texto) | `category` |
|---|---|---|
| Memória | Mais pesada | Bem mais leve |
| groupby e filtros | Mais lentos | Mais rápidos |
| Faz sentido quando | Valores únicos e livres (nome, comentário) | Valores que se repetem (plataforma, gênero, país) |

## Categorizar com apply()

Escreva uma função que recebe **um valor** e devolve a categoria. O `apply` roda a função em cada valor da coluna.

```python
def era_group(year):
    if year < 2000:
        return 'retro'
    elif year < 2010:
        return 'modern'
    elif year >= 2010:
        return 'recent'
    else:
        return 'unknown'     # NaN cai aqui: toda comparação com NaN dá False

df['era_group'] = df['year_of_release'].apply(era_group)
df['era_group'].value_counts()
```

Depois, a coluna nova vira base para agrupar:

```python
df.groupby('score_group')['na_sales'].sum()
```

## Função que olha a linha inteira (axis=1)

Quando a categoria depende de mais de uma coluna, a função recebe a **linha** (uma Series) e lê as colunas pelo nome:

```python
def era_sales_group(row):
    year = row['year_of_release']
    total = row['na_sales'] + row['eu_sales'] + row['jp_sales']
    if year < 2000:
        return 'retro' if total < 1 else 'classic'
    if year < 2010:
        return 'modern' if total < 1 else 'classic'
    return 'recent' if total < 1 else 'big hit'

df['game_category'] = df.apply(era_sales_group, axis=1)
```

> [!regra] apply em coluna × apply no DataFrame
> - `df['col'].apply(f)`: `f` recebe um valor de cada vez.
> - `df.apply(f, axis=1)`: `f` recebe uma linha inteira de cada vez.
> - `df.apply(f)` sem `axis` (ou `axis=0`) manda **colunas** para a função, que quase nunca é o que você quer.

> [!dica] Teste a função antes de aplicar
> Monte linhas falsas com `pd.Series([1989, 0, 0, 0.6], index=cols)` e chame a função nelas. Se cada uma devolver o esperado, aplique no DataFrame.
