## Índices

Todo DataFrame e toda Series têm um índice. O padrão é um `RangeIndex(start=0, stop=n, step=1)`: começa em 0, para antes de `n`, anda de 1 em 1. Você pode trocar:

```python
oceans = pd.Series(['Pacific', 'Atlantic', 'Indian'], index=['A', 'B', 'C'])
oceans.index = [1, 2, 3]          # ou depois de criado

df = df.set_index('state')        # uma coluna vira o índice
df.index.name = None              # tira o nome "state" que fica em cima do índice
```

## loc × iloc

| | `.loc[]` | `.iloc[]` |
|---|---|---|
| Usa | **Rótulos**: nome do índice e da coluna | **Posições**: números 0, 1, 2... |
| Exemplo | `df.loc['state 4', 'insect']` | `df.iloc[3, 2]` |
| Fatia inclui o fim? | Sim: `loc['state 1':'state 3']` traz 3 linhas | Não: `iloc[0:3]` traz 0, 1, 2 |

```desenho loc-iloc
loc usa nomes; iloc usa posições
```

```python
df.loc[['state 1', 'state 3'], ['flower', 'insect']]   # listas de rótulos
df.loc['state 1':'state 3', 'flower':'insect']          # intervalos
df.iloc[[0, 2], 1:]                                     # linhas 0 e 2, da coluna 1 em diante
```

## Máscara: filtrar e escolher colunas

```python
mask = df['jp_sales'] >= 1
df[mask][['name', 'jp_sales']]
```

O segundo par de colchetes recebe uma **lista** de colunas, por isso fica `[['name', 'jp_sales']]`. Para uma coluna só, `['name']` basta.

## query()

Escreve o filtro como texto, mais perto de como você falaria:

```python
df.query("jp_sales > 1")[['name', 'jp_sales']]
df.query("publisher == 'Nintendo'")                   # texto dentro do texto: aspas diferentes
df.query("platform == 'Wii' and genre != 'Sports'")   # and / or / not funcionam aqui
```

## isin(): está na lista?

Mais limpo que encadear vários `==` com `|`.

```python
handhelds = ['3DS', 'DS', 'GB', 'GBA', 'PSP']
df[df['platform'].isin(handhelds)]
df.query("platform in @handhelds")        # @ chama uma variável de fora da string
df.query("platform not in @handhelds")
```

## Filtrar usando estruturas externas

O `@` funciona com dicionário, Series e DataFrame. Diga se quer os valores ou o índice:

```python
df.query("a in @our_dict")            # compara com as CHAVES do dicionário
df.query("a in @our_dict.values()")   # compara com os VALORES
df.query("a in @our_series")          # valores da Series
df.query("c in @our_series.index")    # índice da Series
df.query("c in @our_df.index")        # índice de outro DataFrame
df.query("a in @our_df.b1")           # uma coluna de outro DataFrame
```

## Várias condições

| Python puro / `query()` | pandas (fora do query) |
|---|---|
| `and` | `&` |
| `or` | `\|` |
| `not` | `~` |

```python
df[(df['platform'] == 'Wii') & ~(df['genre'] == 'Sports')]

# críticos OU usuários com nota alta, E gênero em uma lista
df[((df['critic_score'] >= 90) | (df['user_score'] >= 9))
   & (df['genre'].isin(['Role-Playing', 'Strategy', 'Puzzle']))]
```

Cada condição entre parênteses. Quando um "ou" está dentro de um "e", ele ganha parênteses extras.

> [!ex] Exemplo com query e várias regras
> Jogos vendidos nas três regiões, com Japão vendendo mais que América do Norte e Europa somadas, de desenvolvedoras de uma lista:
> ```python
> developers = ['SquareSoft', 'Enix Corporation', 'Square Enix']
> q_string = ("jp_sales > (na_sales + eu_sales) and jp_sales > 0 "
>             "and na_sales > 0 and eu_sales > 0 and developer in @developers")
> df.query(q_string)[['name', 'developer', 'na_sales', 'eu_sales', 'jp_sales']]
> ```

## Substituir com where()

`serie.where(condição, novo_valor)` **mantém** o valor onde a condição é `True` e **troca** onde é `False`. É o contrário do que a intuição pede, por isso a condição costuma vir invertida.

```python
# troca 'NES' pelo nome completo: mantém tudo que é diferente de NES
df['platform'] = df['platform'].where(df['platform'] != 'NES', 'Nintendo Entertainment System')

# mesma coisa com ~
df['platform'] = df['platform'].where(~(df['platform'] == 'NES'), 'Nintendo Entertainment System')

# agrupa editoras raras em 'other'
rare = ['Red Flagship', 'Max Five', '989 Sports']
df['publisher'] = df['publisher'].where(~df['publisher'].isin(rare), 'other')
```

> [!erro] str.replace troca pedaços
> `df['platform'].str.replace('NES', '...')` também mexe em `'SNES'`, que vira `'S...'`. Para trocar o valor inteiro, use `where`, `.loc[condição, 'col'] = valor` ou `replace` sem o `.str`.

## Arsenal do pandas (mapa dos capítulos 2.4 a 3.3)

| Missão | Ferramenta |
|---|---|
| Selecionar | `df['col']`, `df[['c1', 'c2']]`, `df[condição]` |
| Localizar | `.loc[]` por rótulo, `.iloc[]` por posição |
| Montar condição | `==`, `>`, `<`; `isin()`; `query()` |
| Combinar condições | `&` `\|` `~` fora do query; `and` `or` `not` dentro |
| Fonte externa | lista, dict, Series, DataFrame com `@variavel` no query |
| Detectar problema | `isna()`, `duplicated()`, `value_counts(dropna=False)` |
| Substituir ausente/errado | `fillna()`, `.loc[cond, 'col'] = valor`, `where()`, `str.replace()` |
