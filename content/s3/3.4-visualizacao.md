## Para que serve

Gráfico tem dois usos: **analisar** (enxergar padrões que a tabela esconde) e **comunicar** (mostrar a conclusão para outra pessoa).

Regra dos eixos: a **variável independente** (a causa, o que muda por conta própria, como o tempo) vai no eixo X. A **dependente** (o efeito) vai no Y.

## Qual gráfico usar

| Gráfico | Use para | pandas |
|---|---|---|
| Barras | Comparar um número entre **categorias** | `kind='bar'` |
| Histograma | Ver a **distribuição** (frequência) de uma variável numérica | `.hist()` ou `kind='hist'` |
| Linha | Dados **em ordem no tempo**, onde cada ponto se liga ao anterior | padrão do `plot()` |
| Dispersão | **Relação** entre duas variáveis numéricas | `kind='scatter'` |
| Caixa (boxplot) | Mediana, quartis e outliers | ver [4.1](#c4-1) |

```desenho barras-vs-hist
barras comparam categorias; histograma mostra distribuição
```

> [!comp] Barras × histograma
> Barras comparam categorias, e você pode reordenar as barras como quiser. No histograma, o eixo X é a própria variável dividida em faixas (*bins*), as barras se encostam e a ordem é fixa.

## Gráficos que enganam

- Pizza que soma mais de 100%.
- Eixo Y que não começa no zero e transforma uma variação de 5% numa barra "duas vezes maior".
- Eixo com espaçamento irregular entre os valores.
- Cores sem ordem lógica num mapa de escala.
- Informação demais num gráfico só.

## plot(): o básico

```python
import pandas as pd
from matplotlib import pyplot as plt   # pyplot é o módulo de gráficos do matplotlib

df.plot()        # índice no eixo X, cada coluna numérica vira uma linha
plt.show()       # mostra o gráfico
```

O matplotlib é a base. O seaborn é construído em cima dele; o plotly é uma biblioteca separada (gráficos interativos). O `df.plot()` do pandas usa o matplotlib por baixo.

> [!corrigido]
> No caderno ficou: "dentro do Matplotlib existem Seaborn, Plotly, Pyplot".
> O certo: `pyplot` é um módulo do matplotlib; o seaborn é **construído em cima** dele; o plotly é uma biblioteca **separada**.

| Parâmetro | Faz o quê |
|---|---|
| `x=`, `y=` | Colunas dos eixos |
| `kind=` | Tipo: `'line'`, `'bar'`, `'hist'`, `'scatter'`, `'box'`... |
| `title=` | Título |
| `xlabel=`, `ylabel=` | Nome dos eixos |
| `style=` | `'o'` só pontos, `'x'` marcador x, `'o-'` linha e pontos |
| `xlim=`, `ylim=` | Limites dos eixos: `xlim=(0, 30)` |
| `grid=True` | Linhas de grade (padrão: `False`) |
| `figsize=(largura, altura)` | Tamanho em polegadas |
| `legend=False` | Esconde a legenda (padrão: `True`) |
| `alpha=` | Transparência de 0 (invisível) a 1 (sólido) |
| `rot=` | Gira os rótulos do eixo X, em graus |
| `bins=` | Número de faixas do histograma (padrão: 10) |

```python
df.plot(x='days', y='revenue', style='o-', xlim=(0, 30), ylim=(0, 120000),
        figsize=(4, 5), title='Receita por dia', grid=True)
plt.savefig('myplot.png', dpi=300)    # salva o último gráfico
```

## matplotlib + pandas juntos

O jeito mais flexível: o matplotlib cria a figura (`fig`) e o eixo (`ax`), o pandas desenha, e você ajusta pelo `ax`.

```python
fig, ax = plt.subplots(figsize=(12, 8))
df.plot(x='days', y='revenue', style='o-', ax=ax)
ax.set_title('A vs B')
ax.set_xlim(0, 30)
ax.grid(True)
fig.savefig('myplot.png', dpi=300)
```

## Histogramas sobrepostos

```python
df[df['male'] == 1]['height'].plot(kind='hist', bins=30)
df[df['male'] == 0]['height'].plot(kind='hist', bins=30, alpha=0.8)
plt.legend(['Male', 'Female'])     # mesma ordem dos plots
```

Com `alpha` abaixo de 1, dá para ver um histograma através do outro.

## Dispersão

```python
df.plot(x='height', y='weight', kind='scatter', alpha=0.36)
```

Com muitos pontos sobrepostos, um `alpha` baixo mostra onde a nuvem é mais densa.

> [!erro] Linha em dado fora de ordem
> `plot()` sem `kind` liga os pontos na ordem das linhas da tabela. Se o X não estiver ordenado, vira um rabisco. `df.sort_values('height').plot(x='height', y='weight')` resolve.

## Correlação

Mede o quanto duas variáveis andam juntas. O coeficiente de Pearson vai de **−1 a +1**:

```desenho correlacao
de −1 a +1
```

| Valor | Leitura | Exemplo |
|---|---|---|
| Perto de +1 | Positiva forte: uma sobe, a outra sobe | m² e preço da casa |
| Perto de −1 | Negativa forte: uma sobe, a outra desce | distância do centro e preço |
| Perto de 0 | Sem relação linear | m² e idade do dono |

```python
df['height'].corr(df['weight'])     # 0.9166
df.corr()                           # matriz com todos os pares
df.corr().loc['male', ['height', 'weight', 'age']]
pd.plotting.scatter_matrix(df, figsize=(9, 9))   # dispersão de todos os pares
```

> [!erro] Correlação não é causa
> Venda de sorvete e afogamentos sobem juntos no verão. Um não causa o outro: os dois dependem do calor.
> A correlação de Pearson também só enxerga relação **linear**. Uma relação em curva pode dar perto de 0.
