## NaN × None

| | `NaN` | `None` |
|---|---|---|
| Significa | *Not a Number*, um cálculo impossível ou valor que não existe | Ausência de valor |
| Tipo | `float` | `NoneType` |
| Aceita conta? | Sim (o resultado vira `NaN`) | Não, dá erro |
| Aparece em | Colunas numéricas | Colunas `object` |

> [!erro] NaN atrapalha o groupby
> Linhas com `NaN` na coluna de agrupamento somem do resultado. Antes de apagar essas linhas, veja se dá para recuperar o valor.

## Contando ausentes

```python
df.isna().sum()                                 # por coluna
df['source'].value_counts(dropna=False)         # contagem de cada valor, NaN incluso
df['source'].value_counts(dropna=False).sort_index()   # em ordem alfabética, NaN no fim
```

`value_counts()` conta quantas vezes cada valor aparece e ordena do mais frequente ao menos. Por padrão ele **ignora** o `NaN` (`dropna=True`). Passe `dropna=False` para ver os ausentes.

## Filtrando ausentes

```python
df_logs[df_logs['source'].isna()]                     # só as linhas sem source

# source é email E o email NÃO está ausente
df_logs[(df_logs['source'] == 'email') & ~(df_logs['email'].isna())]
```

> [!regra] Condições combinadas no pandas
> - `&` é "e", `|` é "ou", `~` é "não".
> - Cada condição vai entre parênteses. Sem eles, o Python resolve na ordem errada e dá erro.
> - `and` / `or` / `not` não funcionam com Series fora do `query()`.

## Variáveis categóricas e quantitativas

- **Quantitativa:** número de um intervalo, dá para fazer conta. Idade, peso, tempo, receita.
- **Categórica:** valor de um conjunto limitado. Marca, cor, cidade, plano.
- **Lógica (booleana):** `True`/`False` (1/0). Comprou ou não.

## Ausentes em categóricas

Primeiro veja se o ausente tem padrão (está concentrado num grupo) ou é aleatório. Se for aleatório, preencha com um valor padrão:

```python
df_logs['email'] = df_logs['email'].fillna('')     # string vazia

# ou já leia o arquivo sem converter vazios em NaN
df_logs = pd.read_csv('/datasets/visit_log.csv', keep_default_na=False)
df_logs['source'] = df_logs['source'].replace('', 'email')
```

Com `keep_default_na=False`, células vazias viram strings vazias `''` em vez de `NaN`, e aí dá para trocar com `replace`.

> [!def] Os três tipos de ausente
> - **MCAR** (*missing completely at random*): falta ao acaso, sem relação com nada.
> - **MAR** (*missing at random*): a falta depende de outra coluna observada, mas não do próprio valor.
> - **MNAR** (*missing not at random*): a falta depende do próprio valor. Ex.: menores de 18 sem resposta na pergunta sobre álcool. É o caso mais difícil.
>
> MCAR e MAR podem ser preenchidos com valor padrão. MNAR pede investigação.

## Ausentes em quantitativas: média ou mediana

Preencha com um valor representativo:

```desenho media-mediana
um outlier puxa a média, a mediana fica
```

- **Sem outliers relevantes:** média (`mean()`).
- **Com outliers:** mediana (`median()`).

> [!ex] Por que a mediana resiste a outliers
> Cinco salários de 30 mil: média e mediana = 30 mil. Entra um diretor ganhando 90 mil. A média sobe para 40 mil, a mediana continua 30 mil. A mediana representa melhor o salário típico.

```python
age_avg = analytics_data['age'].mean()
analytics_data['age'] = analytics_data['age'].fillna(age_avg)
```

Se os grupos são diferentes, preencha **por grupo** (média do desktop para o desktop, do mobile para o mobile):

```python
desktop = analytics_data[analytics_data['device_type'] == 'desktop']
desktop_avg = desktop['time'].mean()
```

> [!regra] Boas práticas ao preencher
> 1. Nunca preencha a variável principal da análise, nem use ela para preencher outras.
> 2. Anote quando, onde, por que e como preencheu.
> 3. O preenchimento não pode mudar a conclusão. Na dúvida, rode a análise com e sem os preenchidos (análise de sensibilidade).
> 4. Se o ausente é pouco (algo como 5 a 10% dos dados, depende do caso), excluir costuma ser aceitável.

## Taxa de conversão

```formula
Taxa de conversão = compras // visitas
```

```python
visits = df_logs.groupby('source')['user_id'].count()
purchases = df_logs.groupby('source')['purchase'].sum()
conversion = purchases / visits      # divide grupo a grupo
```

## Duplicados

**Achar:**

```python
df.duplicated().sum()          # quantas linhas repetidas
df[df.duplicated()]            # quais são
df['col_1'].value_counts()     # valores que aparecem mais de uma vez sobem para o topo
```

**Duplicados com maiúsculas e minúsculas:** para o Python, `'A'` e `'a'` são diferentes. Padronize com `.str.lower()` ou `.str.replace()` (o `.str` aplica o método de string na coluna inteira).

```python
stock['item'] = stock['item'].str.replace('GB', 'gb')
df_stock['item_lowercase'] = df_stock['item'].str.lower()   # coluna nova: preserva a original
```

**Remover por uma coluna:**

```python
df.drop_duplicates(subset='col_1')      # mantém a primeira ocorrência de cada valor
```

> [!erro] Apagar duplicado pode apagar informação
> Em `phone_stock`, "iPhone Xr 64gb" aparecia duas vezes com estoques 10 e 19. Apagar a segunda linha perde 19 aparelhos. Some antes de apagar:
> ```python
> df_stock.groupby('item_lowercase')['count'].sum()
> ```
