## CSV que não vem no padrão

CSV quer dizer *comma-separated values*, mas o arquivo pode usar outro separador: ponto e vírgula, barra vertical `|`, tabulação (`.tsv`). Lido sem ajuste, tudo cai numa coluna só.

```python
column_names = ['country', 'name', 'capacity_mw', 'latitude',
                'longitude', 'primary_fuel', 'owner']

data = pd.read_csv(
    '/datasets/gpp_modified.csv',
    sep='|',               # o separador do arquivo
    header=None,           # o arquivo não tem linha de cabeçalho
    names=column_names,    # nomes que eu escolho para as colunas
    decimal=',',           # decimal com vírgula (padrão brasileiro)
)
```

| Parâmetro | Para quê |
|---|---|
| `sep=` | Separador das colunas. Padrão: `,` |
| `decimal=` | Separador decimal. Padrão: `.` |
| `header=None` | Avisa que não há cabeçalho. O padrão (`'infer'`) usa a primeira linha como cabeçalho |
| `names=[...]` | Define os nomes das colunas |

> [!erro] Sem header=None, você perde uma linha
> Se o arquivo não tem cabeçalho e você não avisa, a primeira linha de dados vira nome de coluna.

## Excel com várias planilhas

`read_excel` carrega só a primeira planilha. Para outra, use `sheet_name` com o nome ou a posição (0, 1, 2... e `-1` para a última). Os outros parâmetros são os mesmos do `read_csv`.

```python
df_products = pd.read_excel('/datasets/product_reviews.xlsx', sheet_name='products')
df_products.sort_values('id')          # ordena pela coluna id
df_categories = pd.read_excel('/datasets/product_reviews.xlsx', sheet_name=-1)
```

## Primeira olhada

```python
data.info()                 # sempre o primeiro comando num DataFrame novo
n_rows, n_cols = data.shape # shape é uma tupla: (34936, 7)
data.sample(5)              # 5 linhas aleatórias
data.sample(5, random_state=1369)   # as mesmas 5 toda vez que rodar
```

> [!def] Tupla
> Parece lista, mas com parênteses e **imutável**: `('uma', 2, 'três')`. Não dá para trocar, adicionar ou remover itens.

> [!dica] Por que sample e não head
> `head()` mostra só o começo do arquivo, que pode ser diferente do resto (dados mais antigos, um único país). `sample()` dá uma visão mais honesta. O `random_state` (qualquer inteiro de 0 a 4.294.967.295) fixa o sorteio para o resultado ser reproduzível.

## describe()

Em colunas numéricas:

| Linha | Significado |
|---|---|
| `count` | Valores não ausentes |
| `mean` | Média |
| `std` | Desvio padrão |
| `min` / `max` | Mínimo / máximo |
| `25%` / `50%` / `75%` | Quartis (o `50%` é a mediana) |

Em colunas de texto (`object`):

| Linha | Significado |
|---|---|
| `count` | Valores não ausentes |
| `unique` | Quantos valores distintos |
| `top` | O valor mais frequente |
| `freq` | Quantas vezes o `top` aparece |

```python
data.describe()                    # só as numéricas
data['country'].describe()         # uma coluna de texto
data.describe(include='object')    # todas as de texto
data.describe(include='all')       # todas (com NaN onde a medida não se aplica)
```

> [!ver] Ver também
> As medidas do `describe` (média, mediana, desvio padrão, quartis) são explicadas no capítulo [4.1 Estatística descritiva](#c4-1).
