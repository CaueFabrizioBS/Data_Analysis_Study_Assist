## Não confie no tipo que o pandas escolheu

Ao ler um arquivo, o pandas adivinha o tipo de cada coluna. Uma coluna de números com um único `'?'` no meio vira `object` (texto) inteira. Por isso, `df.info()` antes de qualquer conta.

## astype(): converter

```python
df['col1'] = df['col1'].astype('int')     # substitui a coluna
df['nova'] = df['col1'].astype('int')     # cria outra e preserva a original
df.astype('str')                          # o DataFrame todo vira texto (object)
```

> [!erro] astype('int') corta casas decimais sem avisar
> `6.01` vira `6`. Antes de converter, confira se a conversão é segura:
> ```python
> import numpy as np
> np.array_equal(df['col1'], df['col1'].astype('int'))   # True: nada muda. False: vai perder informação
> ```

## to_numeric(): texto para número

Transforma em `int64` ou `float64` conforme o conteúdo (`'1.0'` vira float, `'3'` vira int). O parâmetro `errors` decide o que fazer com o que não é número:

| `errors=` | O que acontece com `'B.0'` |
|---|---|
| `'raise'` (padrão) | Para tudo com erro |
| `'coerce'` | Vira `NaN` |
| `'ignore'` | Fica como está (a coluna continua texto) |

```python
df['user_score'] = pd.to_numeric(df['user_score'], errors='coerce')
```

## to_datetime(): texto para data

```python
df['InvoiceDate'] = pd.to_datetime(df['InvoiceDate'], format='%Y-%m-%dT%H:%M:%SZ')
```

| Código | Significa | Exemplo |
|---|---|---|
| `%d` | Dia (01 a 31) | 17 |
| `%m` | Mês (01 a 12) | 12 |
| `%Y` | Ano com 4 dígitos | 2010 |
| `%y` | Ano com 2 dígitos | 10 |
| `%H` | Hora 0 a 23 | 17 |
| `%I` | Hora 1 a 12 | 05 |
| `%M` | Minuto | 34 |
| `%S` | Segundo | 15 |
| `T`, `Z` | Separador entre data e hora / marca de UTC | `2010-12-17T12:38:00Z` |

> [!erro] 08/03 é março ou agosto?
> No Brasil, `08.03.2021` é 8 de março (`%d.%m.%Y`). Nos EUA, `08/03/2021` é 3 de agosto (`%m/%d/%Y`). Sem o `format`, o pandas pode chutar errado.

## Pegando partes da data

```python
df['InvoiceDate'][0].year        # de um valor só: 2010
df['InvoiceDate'].dt.day         # da coluna inteira: precisa do .dt
df['InvoiceDate'].dt.month
df['InvoiceDate'].dt.hour
df['InvoiceDate'].dt.weekday     # dia da semana (0 = segunda)
pd.DatetimeIndex(df['InvoiceDate']).year   # forma alternativa
```

## Fuso horário

- `tz_localize('UTC')`: só **cola a etiqueta** de fuso. A hora não muda.
- `tz_convert('America/Sao_Paulo')`: **converte** para outro fuso. A hora muda. Só funciona depois do `localize`.

```python
dt = pd.to_datetime('2002-12-20 04:31:00')
dt_utc = dt.tz_localize('UTC')                     # 04:31+00:00
dt_sp = dt_utc.tz_convert('America/Sao_Paulo')     # 01:31-03:00 (ou -02:00 no horário de verão da época)

df['timestamp'].dt.tz_localize('America/Toronto')  # coluna inteira usa .dt
```
