## groupby por várias colunas

```python
df.groupby(['platform', 'genre'])['critic_score'].mean()
```

O resultado tem um índice de dois níveis (plataforma, depois gênero). Por trás está o esquema **split-apply-combine**:

```fluxo
Split: dividir em grupos → Apply: calcular em cada grupo → Combine: juntar os resultados
```

## agg(): cálculos diferentes por coluna

Recebe um dicionário `{coluna: cálculo}`:

```python
grp = df.groupby(['platform', 'genre'])
grp.agg({'critic_score': 'mean', 'jp_sales': 'sum'})
grp.agg({'col2': ['count', 'sum'], 'col3': ['min', 'max']})   # vários por coluna

def double_it(sales):
    return sales.sum() * 2
grp.agg({'jp_sales': double_it})      # função sua também vale
```

## pivot_table(): tabela dinâmica

A mesma ideia da tabela dinâmica do Excel.

| Parâmetro | Vira |
|---|---|
| `index=` | Linhas da tabela |
| `columns=` | Colunas da tabela |
| `values=` | O número que vai no cruzamento |
| `aggfunc=` | Como agregar: `'sum'`, `'mean'` (padrão), `'median'`, `'count'`, `'min'`, `'max'`, `'first'`, `'last'` ou uma lista |

```python
df.pivot_table(index='genre', columns='platform', values='eu_sales', aggfunc='sum')
```

> [!comp] groupby × pivot_table
> `groupby` com uma coluna de valor devolve uma **Series** com índice em vários níveis. `pivot_table` devolve um **DataFrame** em formato de grade, mais fácil de ler e de plotar.

## concat(): empilhar

```python
pd.concat([rpgs, platformers])                  # um embaixo do outro (axis=0)
pd.concat([mean_score, num_sales], axis='columns')   # lado a lado, alinhando pelo índice
```

Empilhar funciona bem quando os DataFrames têm as mesmas colunas.

## merge(): juntar por uma chave

```python
df_1.merge(df_2, on='author', how='inner')
```

| `how=` | Mantém |
|---|---|
| `'inner'` (padrão) | Só as chaves que existem nos dois |
| `'left'` | Tudo da esquerda; da direita, só o que casa (o resto vira `NaN`) |
| `'right'` | Tudo da direita; da esquerda, só o que casa |
| `'outer'` | Tudo dos dois, com `NaN` onde não casou |

- Colunas com o mesmo nome nos dois lados ganham sufixos `_x` e `_y`. Troque com `suffixes=['_1st', '_2nd']`.
- Chaves com nomes diferentes: `left_on='authors', right_on='author'`. As duas colunas aparecem no resultado; tire uma com `.drop('author', axis='columns')`.
- `on=` aceita uma lista para juntar por várias colunas.
- `join()` é um atalho do `merge` que junta pelo índice.
