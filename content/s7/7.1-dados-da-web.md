## Web scraping

Coletar dados de sites para enriquecer uma análise. Ex.: você desconfia que a loja vende mais em dia de chuva e cruza as vendas com dados do clima. Também se chama *web mining* ou *parsing*. Dá para coletar conteúdo (texto, tabelas), estrutura (links) e comportamento de usuários.

- **HTML:** a linguagem da página.
- **Navegador:** o programa que mostra o HTML.
- **HTTP/HTTPS:** as regras de transferência. O **S** é de *secure* (criptografado).

## Requisições: GET e POST

| | `requests.get()` | `requests.post()` |
|---|---|---|
| Para quê | **Pedir** uma página ou dados | **Enviar** dados (preencher formulário, login) |
| Parâmetros | Vão na URL (`?busca=galaxy`) | Vão no corpo da requisição, escondidos |

```python
import requests
req = requests.get('https://loja.com/ofertas', params={'busca': 'galaxy'})
req.status_code     # 200
req.text            # o HTML em texto
```

| Código | Significa |
|---|---|
| 200 | Deu certo |
| 404 | Página não encontrada |
| 500 | Erro no servidor |

## Lendo HTML

```html
<p class="produto">Galaxy S25</p>
```

`<p` abre a tag, `class="produto"` é um atributo, `Galaxy S25` é o conteúdo, `</p>` fecha. Tags ficam umas dentro das outras, formando uma árvore.

| Tag | É |
|---|---|
| `<html>`, `<head>`, `<body>` | Página, bastidores, o que aparece |
| `<title>` | Nome na aba do navegador |
| `<div>`, `<span>` | Caixas para agrupar (bloco / trecho de linha) |
| `<h1>` a `<h6>`, `<p>` | Títulos e parágrafos |
| `<a href="...">` | Link |
| `<img src="...">` | Imagem |
| `<ul>`, `<ol>`, `<li>` | Listas e itens |
| `<table>`, `<tr>`, `<th>`, `<td>` | Tabela, linha, cabeçalho, célula |

`id` identifica **um** elemento único; `class` marca um **grupo** de elementos. Para achar as tags de um site: F12 ou botão direito → Inspecionar.

## Expressões regulares (regex)

Padrões para achar pedaços de texto. Módulo `re`.

| Método | Faz | Devolve |
|---|---|---|
| `re.search(padrão, texto)` | Acha a **primeira** ocorrência | Objeto; use `.group()`. `None` se não achar |
| `re.findall(padrão, texto)` | Acha **todas** | Lista (vazia se nada) |
| `re.split(padrão, texto)` | Corta onde o padrão aparece | Lista |
| `re.sub(padrão, novo, texto)` | Troca o padrão | String nova |

| Símbolo | Significa | Exemplo |
|---|---|---|
| `[abc]` | Um caractere da lista | `[ao]` → a ou o |
| `[^a]` | Qualquer um **menos** esses | |
| `[0-9]`, `[A-Za-z]` | Faixa | |
| `.` | Qualquer caractere (menos quebra de linha) | `c.sa` → casa, cosa |
| `\d` | Dígito | |
| `\w` | Letra, dígito ou `_` | |
| `?` | 0 ou 1 vez | `cores?` → cor, cores |
| `+` | 1 ou mais | `\d+` |
| `*` | 0 ou mais | |
| `^` / `$` | Começo / fim do texto | |
| `\$`, `\.` | O símbolo literal | |

```python
import re
t = 'Leite integral: R$4,23, Manteiga sem sal: R$12,90'
re.findall(r'R\$\d+,\d+', t)        # ['R$4,23', 'R$12,90']
re.findall(r'Galaxy[A-Za-z0-9 -]*', texto)   # nome completo dos Galaxy
```

> [!dica] Montando o padrão
> Pense em quais caracteres o que você quer **pode** ter e coloque todos nos colchetes. O caractere que marca o fim (a vírgula, o `:`) fica de fora, e é ele que faz o padrão parar.
> Acentos: use `[A-Za-zÀ-ÿ]`. O `r` antes das aspas evita que o Python confunda as barras.

> [!erro] Hífen e [A-z]
> - Hífen no meio dos colchetes vira intervalo: `[0-9 -9]` aceita símbolos estranhos. Ponha o hífen no **começo ou no fim**: `[A-Za-z0-9 -]`.
> - `[A-z]` inclui `[ ] ^ _` e outros símbolos que ficam entre o Z e o a. Use `[A-Za-z]`.

## BeautifulSoup

Em vez de caçar padrões no texto, navega pela estrutura do HTML.

```python
from bs4 import BeautifulSoup
soup = BeautifulSoup(req.text, 'lxml')      # 'lxml' é o analisador (parser)

soup.find('h2')                              # primeira tag h2
soup.find_all('p')                           # lista com todas
soup.find('h2').text                         # só o conteúdo
soup.find_all('p', attrs={'class': 'produto'})   # filtra por classe ou id
soup.find('a')['href']                       # valor de um atributo
```

**Tabela do site para DataFrame:**

```python
table = soup.find('table', attrs={'id': 'precos'})
heading = [th.text for th in table.find_all('th')]
content = []
for row in table.find_all('tr'):
    if not row.find_all('th'):                       # pula o cabeçalho
        content.append([td.text for td in row.find_all('td')])
df = pd.DataFrame(content, columns=heading)
```

> [!erro] Lista de listas vira linha, não coluna
> `pd.DataFrame([nomes, precos], columns=['name', 'price'])` dá erro: cada lista interna virou uma **linha**. Monte por colunas: `pd.DataFrame({'name': nomes, 'price': precos})`.
> Lembre também que `.text` devolve string: converta o preço com `pd.to_numeric`.

> [!comp] Regex × BeautifulSoup
> Regex procura **padrões de texto** (preço, e-mail). BeautifulSoup procura pela **estrutura** (a tabela de id tal). Na prática se completam: o BeautifulSoup acha a tag e a regex limpa o texto.

## APIs e JSON

Quando o site oferece uma API, é melhor que raspar HTML: você pede os dados direto e recebe JSON organizado.

```python
params = {'categoria': 'celular', 'limite': 2}
response = requests.get('https://api.loja.com/produtos', params=params)
dados = response.json()           # já vira lista/dicionário Python
pd.DataFrame(dados)               # lista de dicionários → DataFrame
```

| JSON | Python |
|---|---|
| `{ }` | dicionário |
| `[ ]` | lista |
| `"texto"` (sempre aspas duplas) | str |
| `true` / `false` | True / False |
| `null` | None |

`json.loads(texto)` converte texto JSON em Python; `json.dumps(obj)` faz o contrário. Mais detalhes em [5.4](#c5-4).
