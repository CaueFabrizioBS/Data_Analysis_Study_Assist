## Banco de dados relacional

O banco é um conjunto de tabelas.

| Tabela | Banco de dados |
|---|---|
| Coluna | Campo |
| Linha | Registro |
| Célula | Célula |

A **chave primária (PK)** identifica cada registro: nunca se repete e nunca fica vazia. Pode ser uma coluna (número do funcionário) ou várias juntas (**chave composta**), desde que a combinação seja única.

## SELECT, FROM, WHERE

```sql
SELECT name, author        -- quais COLUNAS mostrar
FROM books                 -- de qual TABELA
WHERE pages > 700;         -- quais LINHAS manter
```

É o `books.query('pages > 700')[['name', 'author']]` do pandas. `SELECT *` traz todas as colunas.

> [!erro] O que muda em relação ao Python
> - Igualdade é **um** `=`, não `==`.
> - Texto e data só com **aspas simples**: `'Stephen King'`, `'2013-01-01'`.
> - Comentário é `--`, não `#`.
> - Diferente pode ser `!=` ou `<>`.

| Operador | Exemplo |
|---|---|
| `=`, `!=`, `<>`, `>`, `<`, `>=`, `<=` | `WHERE pages > 1000` |
| `AND`, `OR`, `NOT` | `WHERE author = 'Stephen King' AND NOT genre = 'Thriller'` |
| `BETWEEN a AND b` | `WHERE date_pub BETWEEN '1996-01-01' AND '2000-12-31'` (inclui os limites) |
| `IN (...)` / `NOT IN (...)` | `WHERE genre IN ('Humor', 'Fantasy')` |

> [!regra] AND antes de OR
> Como no Python, o `AND` é resolvido antes. Use parênteses:
> ```sql
> WHERE (author = 'Stephen King' OR author = 'Dean Koontz')
>   AND pages > 700
> ```

## Funções de agregação

Transformam muitas linhas num número só. `AS` dá um apelido para a coluna do resultado.

```sql
SELECT COUNT(*) AS cnt,
       COUNT(publisher_id) AS pub_cnt,
       COUNT(DISTINCT publisher_id) AS pub_uniq
FROM books;                     -- 30 | 28 | 19
```

| SQL | pandas | Conta |
|---|---|---|
| `COUNT(*)` | `len(df)` | Todas as linhas |
| `COUNT(col)` | `df['col'].count()` | Só as não vazias (ignora NULL) |
| `COUNT(DISTINCT col)` | `df['col'].nunique()` | Valores diferentes |
| `SUM(col)` | `.sum()` | Soma (só números) |
| `AVG(col)` | `.mean()` | Média (só números) |
| `MIN(col)` / `MAX(col)` | `.min()` / `.max()` | Funciona com número, data e texto |

O `WHERE` filtra primeiro, a função calcula depois: `SELECT SUM(pages) FROM books WHERE author = 'Dean Koontz'`.

## CAST: converter tipos

Número guardado como texto (`'4.2'`) não aceita `AVG`. Converta na própria consulta:

```sql
SELECT AVG(CAST(rating AS real)) AS average FROM books;   -- jeito por extenso
SELECT AVG(rating::real) AS average FROM books;           -- jeito curto do PostgreSQL
```

A conversão vale só para aquela consulta; a tabela não muda. Funciona no `SELECT`, dentro de funções e no `WHERE` (`WHERE rating::real > 4.3`).

| Tipo PostgreSQL | O que guarda | Python |
|---|---|---|
| `integer` | Inteiro | `int` |
| `real` | Decimal (até 6 casas) | `float` |
| `numeric` | Decimal exato (use no `ROUND`) | |
| `varchar(n)` | Texto com até n caracteres | `str` |
| `text` | Texto de qualquer tamanho | `str` |
| `date` | Data | `date` |
| `timestamp` | Data e hora | `datetime` |
| `boolean` | `TRUE`, `FALSE` ou `NULL` | `bool` |

> [!erro] Duas pegadinhas
> - `CAST('4.43' AS integer)` dá erro: texto com decimal vira `real`, não `integer`.
> - `7 / 2` dá **3** no SQL (inteiro dividido por inteiro corta as casas). Use `CAST(7 AS real) / 2` → 3.5.

## Operadores de texto e contas

| Operador | Exemplo | Resultado |
|---|---|---|
| `\|\|` | `'Leite' \|\| ' integral'` | `'Leite integral'` (concatena) |
| `%` | `7 % 2` | 1 |
| `^` | `2 ^ 3` | 8 |
| `ROUND(x, n)` | `ROUND(price::numeric, 1)` | Arredonda |
| `ABS(x)` | `ABS(-5)` | 5 |
