## Tipos de variável

```fluxo
Variável → Categórica (qualitativa) | Quantitativa (numérica) → Discreta | Contínua
```

| | Discreta | Contínua |
|---|---|---|
| O que é | Valores contáveis, "pulados" | Qualquer valor dentro de um intervalo |
| Exemplos | Convidados, páginas, sacos vendidos | Tempo de espera, peso, altura |
| Macete | Cabe um valor no meio? **Não** | Cabe um valor no meio? **Sim** |

Uma categórica pode até ser guardada como número (vermelho = 1, azul = 2), mas esse número é só um rótulo: não faz sentido somar ou tirar média.

## Histograma de frequência e de densidade

O histograma divide os valores em faixas (*bins*) e conta quantos caem em cada uma. Os limites das faixas mudam muito a leitura, então teste mais de uma opção:

```python
data.hist(bins=4)                                  # 4 faixas de mesmo tamanho
data.hist(bins=[11, 20, 30, 40, 50, 60, 70, 80, 90, 99])   # limites escolhidos
```

Quando as faixas têm larguras diferentes, a altura engana. O **histograma de densidade** resolve: a **área** da barra é a frequência e a altura é a densidade.

```formula
Densidade = frequência // largura da faixa
```

> [!ex] Lendo um histograma de densidade
> Faixa de 2 a 4 com 3 valores: densidade 3 / 2 = **1,5**. Faixa de 4 a 8 com 6 valores: 6 / 4 = **1,5**. As duas têm a mesma densidade, embora a segunda tenha o dobro de valores. A curva de densidade é a versão suavizada da mesma ideia.

## Medidas de localização: média e mediana

- **Média** (μ, "mi"): soma ÷ quantidade. Medida *algébrica*.
- **Mediana**: o valor do meio com os dados ordenados. Com quantidade par, a média dos dois do meio. Medida *estrutural*.

```desenho media-mediana
um outlier puxa a média, a mediana fica
```

```formula
μ = Σ xᵢ // n
```

> [!ex] Qual usar
> Site de doações: a maioria doa pouco, alguns fãs doam centenas. A **média** fica alta e é boa para propaganda. A **mediana** mostra quanto a maioria das pessoas realmente doa.

## Quartis e diagrama de caixa (boxplot)

Os quartis cortam os dados ordenados em quatro partes iguais:

```desenho boxplot-quartis
```

- **Q1** (25%): um quarto dos valores está abaixo.
- **Q2** (50%): a mediana.
- **Q3** (75%): três quartos abaixo.
- **IQR** (intervalo interquartil) = Q3 − Q1: onde ficam os 50% do meio.

```formula
IQR = Q3 − Q1
Limite superior = Q3 + 1,5 × IQR
Limite inferior = Q1 − 1,5 × IQR
```

A caixa vai de Q1 a Q3, com a mediana no meio. Os bigodes vão até o último valor dentro dos limites. O que passa dos limites aparece como ponto solto: **outlier**.

```python
import seaborn as sns
sns.boxplot(dataset)
df.boxplot()            # versão do pandas
```

> [!ex] É outlier?
> Q1 = 25, Q3 = 41 → IQR = 16 → limite superior = 41 + 1,5 × 16 = **65**. O valor 64 **não** é outlier.

> [!erro] Bigode comprido não quer dizer mais clientes
> Comparando dois canais de anúncio, o boxplot com bigode direito bem mais longo mostra que **alguns clientes gastam muito mais** (distribuição assimétrica à direita, média acima da mediana). Não diz nada sobre quantas pessoas o canal alcança.

## Variância e desvio padrão

**Variância** (σ²): média das distâncias até a média, ao quadrado. Quanto maior, mais espalhados os dados.

```formula
σ² = Σ (xᵢ − μ)² // n
σ = √σ²
```

O problema da variância é a unidade: minutos², kg², anos². O **desvio padrão** (σ, "sigma") tira a raiz e volta para a unidade original.

```python
import numpy as np
np.var([1, 2, 3, 4, 5, 6])    # 2.9167
np.std([1, 2, 3, 4, 5, 6])    # 1.7078
np.sqrt(2.9167)               # 1.7078

pd.Series([1, 2, 3, 4, 5, 6]).std()    # 1.8708  ← diferente!
```

> [!erro] numpy e pandas dão desvios diferentes
> O numpy divide por **n** (população). O pandas divide por **n − 1** (amostra). Para os dados 1 a 6, a variância é 2,9167 no numpy e 3,5 no pandas. Para o numpy usar n − 1: `np.var(x, ddof=1)`.

## Covariância

Mede se duas variáveis variam juntas:

```formula
Cov(x, y) = Σ (xᵢ − x̄)(yᵢ − ȳ) // n
```

- **> 0**: andam juntas (casa maior, preço maior).
- **< 0**: andam em sentidos opostos.
- **≈ 0**: sem relação linear.

```python
cov_matrix = np.cov(x, y)     # matriz 2×2: [[var x, cov], [cov, var y]]
cov_matrix[0][1]              # a covariância (linha 0, coluna 1)
```

A covariância depende da unidade, então o número sozinho diz pouco. A **correlação** ([3.4](#c3-4)) é a covariância padronizada entre −1 e +1.

## Distribuição normal e regra dos três sigmas

A distribuição normal (gaussiana) tem forma de sino, simétrica em torno da média. Quanto maior o σ, mais achatado o sino.

```desenho sino-tres-sigmas
```

| Intervalo | Valores dentro |
|---|---|
| μ ± 1σ | ≈ 68% |
| μ ± 2σ | ≈ 95% |
| μ ± 3σ | ≈ 99,7% |

Quase tudo cabe em **(μ − 3σ, μ + 3σ)**. O que fica de fora é atípico.

> [!ex] Quantos prêmios comprar
> 6 mil participantes, 3% acertam em média, desvio de 0,4%.
> μ = 6000 × 0,03 = 180; σ = 6000 × 0,004 = 24.
> Intervalo: 180 − 3 × 24 = **108** até 180 + 3 × 24 = **252** vencedores.

## Assimetria

- **Assimetria positiva** (à direita): cauda longa para a direita. Alguns valores muito altos puxam a média para cima: **média > mediana**. Ex.: renda, tempo no site.
- **Assimetria negativa** (à esquerda): cauda longa para a esquerda: **média < mediana**.
- **Simétrica**: média ≈ mediana.

Dá para saber sem gráfico: compare média e mediana.
