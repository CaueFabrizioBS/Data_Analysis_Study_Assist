## Por que limpar antes de analisar

Pré-processamento é a limpeza: renomear colunas, tratar ausentes, tirar duplicados. A regra é **GIGO** (*garbage in, garbage out*): dado ruim na entrada dá resultado ruim na saída, por melhor que seja a análise.

Os problemas mais comuns:

- **Valores ausentes**, em geral `NaN`.
- **Duplicados**, que inflam contagens e somas.
- **Erros de apresentação**, como um espaço invisível no nome da coluna.

## Renomear colunas

Comece com `df.info()` ou `df.columns`. Em `['Celestial bodies ', 'MIN', 'MAX']` há três problemas: espaço sobrando no fim, padrão misturado (maiúscula e minúscula) e nomes que não dizem nada.

O padrão é **snake_case**: tudo minúsculo, palavras separadas por `_`, sem espaço nem acento.

```python
columns_new = {
    'Celestial bodies ': 'celestial_bodies',
    'MIN': 'min_distance',
    'MAX': 'max_distance',
}
celestial = celestial.rename(columns=columns_new)        # devolve uma cópia
celestial.rename(columns=columns_new, inplace=True)      # altera o próprio df
```

Para muitas colunas, um `for` resolve:

```python
new_col_names = []
for old_name in celestial.columns:
    name = old_name.strip().lower().replace(' ', '_')
    new_col_names.append(name)
celestial.columns = new_col_names
```

## Valores ausentes

O esperado é aparecer como `NaN` (colunas numéricas) ou `None` (colunas `object`). Mas às vezes o ausente vem disfarçado: `0`, `?`, `NN`, `n/a`. Esses o `isna()` não pega.

```python
cholera.isna().sum()    # ausentes por coluna (isna e isnull são a mesma coisa)
```

Duas saídas: **preencher** ou **remover**.

```python
# preencher
cholera['imported_cases'] = cholera['imported_cases'].fillna(0)

# remover linhas que têm ausente em QUALQUER uma dessas colunas
cholera = cholera.dropna(subset=['total_cases', 'deaths', 'case_fatality_rate'])

# remover colunas que têm algum ausente
cholera = cholera.dropna(axis='columns')

# remover colunas ou linhas pelo nome, tendo ausente ou não
cholera = cholera.drop(labels=['notes'], axis='columns')
df.drop(labels=[0, 2, 5], axis='index')
```

| Termo | Faz o quê |
|---|---|
| `inplace=True` | Altera o DataFrame original em vez de devolver uma cópia |
| `fillna(valor)` | Preenche ausentes |
| `dropna()` | Remove linhas (ou colunas) com ausentes |
| `subset=[...]` | Limita o `dropna` a essas colunas |
| `axis` | Linhas: `0`, `'index'` ou `'rows'`. Colunas: `1` ou `'columns'` |
| `labels=[...]` | Quais linhas (índice) ou colunas (nome) o `drop` remove |

> [!corrigido]
> No caderno ficou: "`dropna(subset)` retira as linhas zeradas em todas essas colunas".
> O certo: tira as linhas com valor **ausente (NaN)** em **qualquer** uma delas. Zero não é ausente.

> [!regra] Ordem sugerida
> 1. `fillna` no que dá para preencher.
> 2. `dropna(subset=...)` nas linhas que ficaram sem salvação.
> 3. `drop` ou `dropna(axis='columns')` para colunas inúteis.

## Duplicados explícitos

Linhas idênticas em todas as colunas.

```python
df.duplicated().sum()         # quantas linhas duplicadas
df = df.drop_duplicates().reset_index(drop=True)
```

Depois de apagar linhas, o índice fica com buracos (0, 1, 3, 4...). `reset_index()` renumera, e `drop=True` evita que o índice antigo vire uma coluna nova.

```fluxo
drop_duplicates() → reset_index() → drop=True
```

## Duplicados implícitos

Mesma coisa escrita diferente: `'Roger Federer'`, `'Roger Federerr'`, `'Roger Fedrer'`.

```python
tennis['name'].unique()     # lista os valores distintos: é aqui que você enxerga o erro
tennis['name'].nunique()    # quantos são
```

Corrija com `replace`. Para vários erros, uma função:

```python
def replace_wrong_values(df, column, wrong_values, correct_value):
    for wrong_value in wrong_values:
        df[column] = df[column].replace(wrong_value, correct_value)
    return df

tennis = replace_wrong_values(tennis, 'name', ['Roger Federerr', 'Roger Fedrer'], 'Roger Federer')
```

## Agrupamento (groupby)

Três passos: **dividir** a tabela por grupos, **aplicar** um cálculo em cada grupo, **combinar** os resultados.

```desenho groupby
dividir, aplicar, combinar
```

```python
exoplanet.groupby('discovered').count()               # quantos por ano
exoplanet.groupby('discovered')['radius'].mean()      # raio médio por ano
```

`groupby` sozinho não mostra nada (só `<DataFrameGroupBy object>`). Precisa de um cálculo depois: `count`, `sum`, `mean`...
