## DataFrame

pandas é a biblioteca para trabalhar com tabelas grandes. A tabela se chama **DataFrame**: linhas com um **índice** (0, 1, 2...) e colunas com nome. Uma coluna sozinha é uma **Series**.

```desenho dataframe
linhas com índice, colunas com nome
```

```python
import pandas as pd       # pd é o apelido (alias) padrão

atlas = [['France', 'Paris'], ['Russia', 'Moscow'], ['China', 'Beijing']]
geography = ['country', 'capital']
world_map = pd.DataFrame(data=atlas, columns=geography)
```

## Lendo arquivos

```python
df = pd.read_csv('/datasets/music_log.csv')     # CSV: valores separados por vírgula
df = pd.read_excel('/datasets/music_log.xlsx')  # Excel
```

No CSV, a primeira linha vira o nome das colunas e cada vírgula separa uma coluna.

## Primeira olhada

| Comando | Mostra |
|---|---|
| `df.head()` / `df.head(3)` | Primeiras 5 (ou 3) linhas |
| `df.tail()` | Últimas linhas |
| `df.shape` | `(linhas, colunas)`. `df.shape[0]` = só linhas |
| `df.dtypes` | Tipo de cada coluna |
| `df.columns` | Nomes das colunas |
| `df.info()` | Tudo junto: linhas, colunas, não nulos por coluna, tipos e memória |

Os nomes dos tipos mudam um pouco do Python para o pandas:

| Python | pandas |
|---|---|
| `str` | `object` |
| `int` | `int64` |
| `float` | `float64` |
| `bool` | `bool` |

> [!dica] info() já mostra os ausentes
> Se a coluna tem 67963 linhas e `info()` mostra `65223 non-null` em `genre`, faltam 2740 valores ali.

## Indexação com .loc

`.loc[linha, coluna]` usa o **rótulo** do índice e o **nome** da coluna.

| Quero | `.loc` | Abreviado |
|---|---|---|
| Uma célula | `df.loc[7, 'genre']` | |
| Uma coluna | `df.loc[:, 'genre']` | `df['genre']` |
| Várias colunas | `df.loc[:, ['Artist', 'genre']]` | `df[['Artist', 'genre']]` |
| Colunas em sequência | `df.loc[:, 'user_id':'genre']` | |
| Uma linha | `df.loc[1]` | |
| Da linha 1 até o fim | `df.loc[1:]` | `df[1:]` |
| Até a linha 3 | `df.loc[:3]` (**inclui** a 3) | `df[:3]` (**não inclui** a 3) |
| Linhas 2 a 5 | `df.loc[2:5]` (inclui a 5) | `df[2:5]` (não inclui a 5) |

> [!erro] Fatia com .loc inclui o fim
> Diferente das listas, `.loc[2:5]` traz as linhas 2, 3, 4 **e 5**. A fatia abreviada `df[2:5]` segue a regra das listas e para na 4.

## Filtrando com condição (indexação lógica)

`df['genre'] == 'pop'` devolve uma Series de `True`/`False`, uma por linha. Colocando isso dentro de `df[...]`, ficam só as linhas `True`:

```python
df.loc[df.loc[:, 'genre'] == 'pop']   # completo
df.loc[df['genre'] == 'pop']          # misto
df[df['genre'] == 'pop']              # abreviado (o mais usado)
```

Operadores: `==`, `!=`, `<`, `>`, `<=`, `>=`.

## Contar, somar, média

Filtra, escolhe a coluna, aplica o cálculo. Dá para fazer em uma linha:

```python
# duração média das músicas pop
df[df['genre'] == 'pop']['total play'].mean()        # 90.37

# quantas músicas tocaram MAIS de 180 segundos
df[df['total play'] > 180]['total play'].count()     # 19065

# quanto tempo um usuário passou ouvindo
df[df['user_id'] == '174C0ED6']['total play'].sum()  # 1003.63
```

```fluxo
Filtrar linhas → Escolher a coluna → mean / count / sum
```
