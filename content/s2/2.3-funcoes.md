## Sintaxe

Variável guarda um valor. Função guarda uma **lógica**: você escreve uma vez e reaproveita com valores diferentes.

```python
def omelet(eggs_number):                      # def + nome + (parâmetros) + :
    result = 'A omelete está pronta! Ovos usados: ' + str(eggs_number)
    return result                             # o que a função devolve

def square(x):
    return x ** 2

print(square(5))   # 25
```

> [!def] Parâmetro × argumento
> **Parâmetro** é o nome na definição (`x` em `def square(x)`). **Argumento** é o valor que você passa na chamada (`5` em `square(5)`).

## Por que usar: tirar repetição

Sem função, a mesma regra se repete para cada item ("desconto de 10% se a quantidade passar de 5"):

```python
item_total_1 = item_price_1 * item_quantity_1
if item_quantity_1 > 5:
    item_total_1 *= 0.9
# ...e de novo para o item 2, e de novo para o item 3
```

Com função, a regra fica num lugar só e as variáveis viram parâmetros:

```python
def calculate_total_price(price, quantity):
    total = price * quantity
    if quantity > 5:
        total *= 0.9
    return total

calculate_total_price(20.0, 20)   # 360.0
calculate_total_price(30.0, 1)    # 30.0
calculate_total_price(10.0, 6)    # 54.0
```

## Funções de filtragem

O filtro de tabela do Sprint 1 vira uma função reaproveitável:

```python
def filter_by_timing(data, target_duration):
    filtered_result = []
    for row in data:
        if row[4] > target_duration:
            filtered_result.append(row)
    return filtered_result
```

## Parâmetros com valor padrão e argumentos nomeados

```python
def omelet(cheese, eggs_number=2):    # eggs_number vale 2 se ninguém passar nada
    ...

omelet(True)                          # usa 2 ovos
omelet(eggs_number=3, cheese=True)    # nomeados: a ordem não importa
```

## Variáveis locais e globais

- **Local:** criada dentro da função. Só existe lá dentro.
- **Global:** criada fora de qualquer função. Vale no código todo.
- Se uma local tem o mesmo nome de uma global, dentro da função vale a local. A global continua intacta do lado de fora.

```python
result = 'A omelete está pronta!'          # global

def omelet(cheese, eggs_number=2):
    result = 'Ovos usados: ' + str(eggs_number)   # local, outra variável
    print(result)

omelet(cheese=True, eggs_number=3)   # Ovos usados: 3
print(result)                        # A omelete está pronta!  (a global não mudou)
```

> [!erro] print não é return
> `print` só mostra na tela. Sem `return`, a função devolve `None` e você não consegue guardar o resultado numa variável.
