## O que é

Dicionário guarda pares **chave: valor**. Parece uma lista, só que em vez de buscar pela posição (`lista[0]`), você busca pelo nome (`dic['SU2222']`).

```desenho dicionario
busca pelo nome da chave, não pela posição
```

```python
schedule = {
    'SU2222': '12.06.18 12:30',
    'SU1111': '12.06.18 14:05',
    'SU0777': '12.06.18 17:00',
}
```

- Criado com chaves `{}`.
- Dois pontos separam a chave do valor; vírgula separa os pares.
- O valor pode ser de qualquer tipo (até lista ou outro dicionário). A chave precisa ser imutável: string, número, tupla.
- `len(dic)` conta quantos pares existem.

## Lendo valores

```python
financial_info = {'Coca-Cola': 45.15, 'Nike': 97.99, 'Walmart': 130.68}

financial_info['Coca-Cola']          # 45.15
financial_info['Pepsi']              # KeyError: a chave não existe
financial_info.get('Pepsi')          # None, sem erro
financial_info.get('Pepsi', -1)      # -1  (valor padrão escolhido por você)
```

## Adicionando, atualizando e removendo

```python
financial_info['Walt Disney'] = 119.34   # cria (ou sobrescreve) a chave

if 'Walt Disney' not in financial_info:  # ou: financial_info.get('Walt Disney') is None
    financial_info['Walt Disney'] = 119.34
else:
    financial_info['Walt Disney'] += 3.2

del financial_info['Nike']                       # apaga
walmart_price = financial_info.pop('Walmart')    # apaga e devolve o valor
```

> [!corrigido]
> No caderno ficou: `financial_info.get['Walt Disney'] == None`.
> O certo: `get` é método, leva **parênteses**: `.get('Walt Disney')`.

## Agrupar valores por chave

Caso clássico: percorrer uma lista de clientes e juntar as rendas por área. Cada chave guarda uma **lista** de valores.

```python
clients = [
    [32456, 'Jack Wilson', 32, 150000, 'Healthcare'],
    [34591, 'Nina Brown', 45, 250000, 'Telecom'],
    # ...
]

incomes_per_field = {}                 # 1. dicionário vazio
for client in clients:                 # 2. uma linha por vez
    field = client[-1]                 # 3. última coluna: a área
    income = client[-2]                #    penúltima: a renda
    if incomes_per_field.get(field) is None:
        incomes_per_field[field] = [income]       # 4. área nova: cria a lista
    else:
        incomes_per_field[field].append(income)   # 5. área já existe: soma à lista
```

Resultado: `{'Healthcare': [150000, 193000], 'Telecom': [250000, 310000], ...}`
